# SKI KNIGHT

SKI KNIGHT is a Godot 4 2D skiing action-exploration game. The player rides through an interconnected snowy mountain, fights enemies, unlocks movement skills, and climbs toward the Snow King.

## Current Features

- Momentum-based skiing movement, jumping, braking, combat, damage, and respawn.
- Five playable map areas: snow entrance, glacier maze, blizzard highlands, ice cave, and snowy peak.
- Enemy and boss encounters with stage scaling, drops, gold, save points, shops, gates, and equipment unlocks.
- Narrative interaction points, paper notes, minimap markers, wind columns, breakable ice platforms, and cable cars.
- Pixel-art placeholder visuals plus asset prompt docs for future sprite, tileset, background, UI, and audio production.

## Run

1. Install Godot 4.6 or newer.
2. Open `game/project.godot` in Godot.
3. Run the project from the editor.

## Repository Notes

- Source assets, scenes, scripts, and Godot `.import` sidecar files are tracked.
- Generated cache and exported builds are ignored: `game/.godot/` and `game/build/`.
- Design and balance documents live at the repository root and in `game/assets/art_prompts/`.
